# Synthetic fixture inventory

All identifiers, dates, prices, companies and expected relations are invented for offline acceptance. AAA/aaa, BRK/BRK.B/BRK/A are distinct exact tape/directory identities; only the actual publisher declaration transforms raw input. FB remains FB in this supplied directory and is not mapped to META. Expected inventory is explicit and independent from the diagnostic implementation. Tests encode gzip tape and TAQP1 print snapshots into private temporary files; no market artifacts are tracked.
