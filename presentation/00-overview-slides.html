The goal

Make it as production-like as possible

Start from an engine that is already exchange-grade — the LMAX BLP benches ~6M ops/s, replays deterministically from its journal, and fails over in ~2–3s — and add real production capabilities on top, one state at a time, without ever giving up that core's determinism.

The same core is the right foundation for three very different kinds of trading system — and each defines "good" differently. That choice is what shapes the roadmap.

Where we are & what's next

Core done, OMS building, HFT deferred

  • ✓ Exchange core — done, and HA-hardened. Exchange-grade throughput, determinism, and HA failover (YU02) validated live; the replication leg rebuilt on Aeron + SBE (YU11), then the hand-built HA replaced by Raft consensus — off-plane sub-second failover, split-brain impossible (YU12).
  • ▸ Sell-side OMS — actively building. Risk, control, settlement/compliance, EOD, tick data, execution algos, ops, and the FIX counterparty front door all landed (YU03–YU10).
Across all three, today's ceiling isn't the engine (~6M ops/s) — it's the edges: REST/JSON ingress and the projector→DB write path (~1k rows/s). Binary (SBE/Aeron) ingress is both the throughput lever and the FIX-gateway prerequisite.
